How to center a div with CSS?

15

I've been trying to center a div both horizontally and vertically but nothing seems to work. I've tried several methods including:

  • Using display: flex with justify-content: center and align-items: center
  • Using position: absolute with top: 50% and left: 50%
  • Using CSS Grid
  • Using transform: translate(-50%, -50%)

But none of these methods work consistently across different browsers. What is the most reliable way to center a div in 2024?
